# بوت الصفحات 🤖

بوت تليجرام بيعمل صفحات إنترنت (Landing Pages) جاهزة لأي نشاط تجاري.
العميل يكلم البوت، يجاوب على كام سؤال، ويستلم ملف HTML فيه منتجاته
وزرار طلب على واتساب على رقمه.

## البوت بيعمل إيه؟

1. العميل يبعت `/start`
2. البوت يسأله: مجالك إيه؟ (أثاث - أكل - ملابس - خدمات - تاني)
3. يسأله: اسم النشاط؟
4. يسأله: رقم الواتساب اللي العملاء هيطلبوا عليه؟
5. يسأله: المنتجات وسعرها، واحد ورا التاني لحد ما يقول خلاص
6. البوت يعمله صفحة HTML شيك (عربي، من اليمين للشمال) ويبعتهاله ملف

الصفحة اللي بتطلع تقدر ترفعها مجانًا على GitHub Pages أو Netlify Drop
ويبقى عندك لينك شغال تبعته لأي حد.

## اللي محتاجه عشان تبدأ

- حاجة واحدة بس: **توكن البوت من BotFather** (مجاني، دقيقتين)
- Python 3.10 أو أجدد

## الخطوة 1: اعمل البوت وخد التوكن

1. افتح تليجرام ودوّر على **@BotFather** وكلمه
2. ابعت `/newbot`
3. هيسألك عن اسم البوت: اكتب أي اسم (مثلاً: بوت الصفحات)
4. هيسألك عن اليوزرنيم: لازم ينتهي بـ `bot` (مثلاً: `my_pages_bot`)
5. هيبعتلك التوكن: حاجة شكلها كده `123456:ABC-DEF...` — خده كوبي

## الخطوة 2: شغّل البوت على جهازك (للتجربة)

افتح الترمينال في فولدر المشروع واعمل:

```bash
pip install -r requirements.txt
cp .env.example .env
```

بعدين افتح ملف `.env` وحط التوكن مكان `ضع_التوكن_هنا`:

```
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
```

وشغّل:

```bash
python bot.py
```

روح كلّم البوت على تليجرام وابعت `/start` — لازم يرد عليك.

## الخطوة 3: خليه شغال 24 ساعة (استضافة)

البوت ده بيشتغل بنظام "polling" يعني البرنامج لازم يفضل شغال طول الوقت.
لو قفلت جهازك، البوت هيسكت. أسهل طريق مجاني:

### Railway (الأسهل، من غير فيزا)

1. اعمل حساب على [railway.com](https://railway.com) بجيتهاب (من غير كارت)
2. ارفع المشروع ده على GitHub (New repository → ارفع الملفات)
3. في Railway: **New Project → Deploy from GitHub repo** واختار المشروع
4. من **Variables** ضيف: `TELEGRAM_BOT_TOKEN` = التوكن بتاعك
5. Railway هيثبّت المتطلبات ويشغّل `python bot.py` لوحده

حسابك الجديد بياخد 5 دولار رصيد تجريبي لمدة 30 يوم، وبعدهم دولار واحد
مجاني كل شهر. البوت الصغير ده ممكن يخلّص الدولار قبل آخر الشهر، فلو البوت
وقف ادفع خطة Hobby (5 دولار/شهر) أو شوف البديل اللي تحت.

### Oracle Cloud Always Free (مجاني للأبد، بس محتاج فيزا وخطوات أكتر)

لو عايز سيرفر مجاني 24 ساعة من غير حدود: Oracle Cloud عندها طبقة
"Always Free" فيها جهاز افتراضي صغير. التسجيل بيطلب كارت (بس مش بيسحب
فلوس)، والإعداد فيه شوية خطوات لينكس. فيه شروحات كتير على يوتيوب باسم
"Oracle Cloud free telegram bot".

## (اختياري) الوصف الذكي للمنتجات

البوت شغال كامل من غير أي ذكاء اصطناعي. لو حبيت البوت يكتب وصف تسويقي
لكل منتج لوحده، افتح ملف `ai_hook.py` — فيه مثال جاهز محتاج بس مفتاح
API في `.env` زي:

```
AI_API_KEY=المفتاح_هنا
```

## ملفات المشروع

| الملف | وظيفته |
|---|---|
| `bot.py` | كود البوت كله (المحادثة + توليد الصفحة) |
| `template.html` | شكل الصفحة اللي بتتعمل — عدّل في التصميم براحتك |
| `ai_hook.py` | (اختياري) الوصف الذكي للمنتجات |
| `pages/` | الصفحات اللي البوت بيعملها بتتحفظ هنا |
| `requirements.txt` | المكتبات المطلوبة |
| `.env.example` | نموذج ملف الإعدادات — اعمل منه نسخة باسم `.env` |

## حدود النسخة دي

- الصفحة ملف HTML بس، مش موقع عليه دومين — لازم ترفعها على استضافة
  بنفسك (GitHub Pages / Netlify Drop) عشان تاخد لينك
- مفيش قاعدة بيانات: لو البوت اتقفل في نص محادثة، العميل يعمل `/start` من الأول
- عميل واحد بيكلم البوت في نفس الوقت من نفس الشات (ده الطبيعي في تليجرام)
